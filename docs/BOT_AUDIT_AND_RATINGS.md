# Bot Audit & Rating Report (134 Curated Bots)

This document outlines the evaluation methodology and ratings for the 134 bots audited and maintained within the ecosystem.

---

## 🏆 Rating & Quality Methodology

Every bot undergoes systematic verification based on 5 core criteria:
1. **Payout Reliability**: Documented on-chain proofs or verified bot balance withdrawals.
2. **Uptime & Stability**: Minimal server outages and consistent API response times.
3. **Task Automation Feasibility**: Programmatic endpoints accessible via reverse-engineered REST APIs or MTProto events.
4. **Anti-Bot Resistance**: Transparent verification requirements without invasive Cloudflare Turnstile blocks.
5. **Community Trust**: Active user community and legitimate token listing potential.

## 🚫 Blacklist & Removal Policy

Bots are permanently excluded and migrated to inactive status if they exhibit any of the following:
- Requiring upfront deposit payments to unlock accrued withdrawal balances.
- Inactive endpoints returning persistent HTTP 404/502 errors for over 14 consecutive days.
- Imposing unresolvable biometric or invasive third-party verification walls.
